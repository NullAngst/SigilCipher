# Changes

2026.11.03 - License

* Added `LICENSE`, CC BY-ND 4.0, with the full official text
* Copyright, license summary and license URL embedded in both fonts' name tables
* License section added to the README
* Version bumped to 1.001

Reasons for changes: the font needed a license that lets anyone use it anywhere while blocking modified versions from being shared.

2026.11.03 - Initial release

* Regular and Bold weights, as TTF and WOFF2
* All 26 letters, digits 0 to 9, and the punctuation `. | - , :`
* A, G, I, L, N, R, S, T, U, 3 and 5 match the glyphs on the NULL ANGST and 35 RUINS seal rings exactly
* Lowercase types the same sigil as uppercase
* `|` types the ring's diamond marker and `.` types its word-separator dot
* `build_font.py` draws every glyph from stroke definitions and can output a key image with `--specimen`

Reasons for changes: the seal rings used a hand-built cipher with only the letters needed for NULL ANGST and 35 RUINS. This fills in the rest of the alphabet so any word can be written in it, and makes it typeable anywhere.
